我是 hpoenixf，拥有 **10 年开发经验、5 年金融业务系统研发经验**。全栈偏前端，专注金融科技与 AI Agent 工程实践。

2016 年起从事软件研发，具有前端工程背景，曾就职于阿里、腾讯及外企。我把前端与交互经验带入 Agent 系统设计，关注从业务需求、工程实现到结果交付的完整链路。这里分享可核对的实现、架构取舍与失败经验，帮助开发者把文章中的思路用于自己的工程判断。

我关注三个相互关联的问题：**怎样让金融数据与计算结果可信、怎样让 Agent 完成从研究到交付的完整任务、怎样用 AI 辅助研发并持续控制系统复杂度。**

### 正在做的公开项目

我把 Agent 工程实践拆成两条相互对应的线：一条提供可运行的实现，一条解释设计取舍。

- **[Open ETF Agent](https://github.com/hpoenixf/open-etf-agent)**：面向开发者的研究 Agent 工程练习，从离线合成文档示例开始，逐步理解工具调用、子代理协作、结果交付与过程观测。可以对照文章运行代码、检查证据；它不是实时基金投研或交易服务。[阅读模块导览](https://hpoenixf.com/eff-agent-article/open-etf-agent)。
- **[ETF Agent Engineering Notes](https://hpoenixf.com/eff-agent-article/)**：围绕 Agent 模块机制、架构设计与研发方法的中英文工程笔记。把实现、验证入口和失败边界放在一起，方便读者顺着问题深入，而不只看结论。[文章源码](https://github.com/hpoenixf/eff-agent-article)。
